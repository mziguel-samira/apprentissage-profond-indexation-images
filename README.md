# Image Indexing by Visual Content (Deep Learning)

This project indexes images by their visual content using a pre-trained CNN
(**VGG16** or **ResNet50**) and searches for similar images with **cosine
similarity**.

## Features

- Extract deep visual features from images using TensorFlow/Keras pre-trained models.
- Build a CSV index file containing image paths and feature vectors.
- Search for similar images from the index using cosine similarity.
- Optional visualization of query and results with matplotlib.

## Project structure

- `image_indexing.py`
  - Main script (indexing + search CLI)
- `requirements.txt`
  - Python dependencies

## Requirements

Install dependencies:

```bash
pip install -r requirements.txt
```

## Usage

Run commands from the project root directory.

### 1) Build an image index (CSV)

```bash
python image_indexing.py index \
  --image-dir /path/to/images \
  --output-csv image_index.csv \
  --model vgg16
```

Parameters:

- `--image-dir`: Directory containing images to index.
- `--output-csv`: Output CSV file.
- `--model`: `vgg16` or `resnet` (default: `vgg16`).

### 2) Search similar images

```bash
python image_indexing.py search \
  --query-image /path/to/query.jpg \
  --index-csv image_index.csv \
  --model vgg16 \
  --top-k 5 \
  --show
```

Parameters:

- `--query-image`: Query image path.
- `--index-csv`: CSV index generated by the `index` command.
- `--model`: Model used for indexing (`vgg16` or `resnet`), must match the index.
- `--top-k`: Number of most similar images to return (default: `5`).
- `--show`: Display query and results with matplotlib.

## Notes

- Supported image extensions: `.jpg`, `.jpeg`, `.png`, `.bmp`, `.tiff`, `.webp`.
- Feature vectors are L2-normalized before similarity search.
- Similarity scores are cosine similarities in `[0, 1]` for normalized vectors.

## Example workflow

```bash
python image_indexing.py index --image-dir ./images --output-csv ./index.csv --model resnet
python image_indexing.py search --query-image ./images/example.jpg --index-csv ./index.csv --model resnet --top-k 3 --show
```
